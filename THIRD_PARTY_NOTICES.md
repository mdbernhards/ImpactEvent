# Third-party scope and draft credits

## Included framework-derived code

`Assets/TheOneFramework/Core/YarnSpinnerFunctions/YarnSpinnerFunctions.cs` is a
locally modified integration from TheOneFramework, used for the CMGT Saxion
Design Fundamentals course. The upstream project identifies itself as MIT
licensed: https://github.com/YvensFaos/TheOneFramework.

The original local license text, including `Copyright (c) 2024 acdh`, is retained
unchanged in `ThirdPartyNotices/TheOneFramework-LICENSE.md`.

## Dependencies not redistributed

- Unity packages: obtained through the Unity Package Manager; versions are
  recorded in the private game's manifest and lock file.
- Yarn Spinner: `dev.yarnspinner.unity`, from
  https://github.com/YarnSpinnerTool/YarnSpinner-Unity.git. The resolved revision
  is retained in the lock file.
- TheOneFramework base components and Unity Starter Assets: omitted from the
  public selection. Starter Assets has a separate Unity Companion License
  notice; the framework MIT notice is not applied to it.
- MB Road System 2.2.1: omitted embedded package. Its local license file is empty;
  redistribution permission has not been established.
- `IntVariable.cs`: omitted pending review. Its header credits J.C. Wichman, so
  it is not presented as the project author's own implementation.
- Unity Asset Store content and other uncertain art, audio, models, textures,
  fonts, scenes, and prefabs: omitted. No assumption is made that free assets
  may be redistributed as source files.
